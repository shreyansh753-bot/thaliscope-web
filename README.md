# Thaliscope (web build)

Built web version of Thaliscope, an app that shows the macros and micronutrients in Indian meals using ICMR-NIN food data.
Live at https://shreyansh753-bot.github.io/thaliscope-web/

Food data: Indian Nutrient Databank (Vijayakumar et al., Curr Dev Nutr 2024) and Indian Food Composition Tables 2017 (ICMR-NIN). Packaged foods: Open Food Facts (ODbL).
General information only; not medical advice.
